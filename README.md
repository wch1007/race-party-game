# 骰子派对 · Dice & Dash

Three.js 制作的 3D 派对接力桌游。浏览器即开即玩：糖果运动场、40 名角色、100 格赛道、可干预的六面骰。

## 开始玩

安装 Node.js 22.15 或更高版本，在项目目录运行：

```sh
npm ci
npm run dev
```

打开 http://localhost:5173 。Windows 可双击 **启动游戏.cmd**。

- **单人练习**：选 4 名搭档，与 AI 比赛。
- **本地派对**：2–4 人共用键鼠，各队选 4 人；同队不能重复，不同队可以同选。
- **联机房间**：运行 `npm run server`，创建房间或输入六位房间码加入。默认 `ws://localhost:8787`；局域网好友使用房主电脑的 IP 地址，开放 8787 端口及网页服务端口。公网需要自行部署服务和使用 `wss://`，本项目不包含公共匹配服务器、NAT 穿透和 Steam 接入。

## 玩法与操作

四人接力，**全队共跑一圈 100 格**。第 24、49、74 格交棒；越过也能交接，恰好停在交接点奖励下一棒一个额外回合。第 4 棒到达 100 格获胜。候选池每局从 40 人中抽 10 人。

| 操作 | 效果 |
| --- | --- |
| 骰盘上拖拽松手 / 甩出骰子按钮 | 投骰；拖拽决定表现轨迹，基础点数均匀随机 |
| 骰子临停后的 W/A/S/D / 方向按钮 | 按住蓄力，松手吹风 |
| 干预时按住骰盘 / 振桌按钮 | 蓄力振桌，点击位置决定方向 |
| P1–P4 按钮 | 本地模式切换干预队；每队每骰各有一次风和一次振桌 |
| Q / 技能按钮 | 按技能要求在投骰前或落定后使用 |
| 鼠标中键拖动 / 滚轮 | 平移 / 缩放，可切换的斜俯视／顶视／低位／反向视角 |
| Esc / 暂停 | 本地暂停（含干预计时和动画） |

骰子先滚动约 1.7 秒，然后进入 5 秒抢骰面窗口。角色技能可延长或缩短窗口。力度在 10%–100% 间以 0.8 秒周期往返，2 秒自动释放。窗口截止后先进行 1.25 秒全员亮招，再停顿 0.28 秒，播放合力翻面和最终落定；总演出约 2.9 秒后才读取最终骰面。人类玩家可在落定后使用技能并确认移动。

格子效果提前显示：绿 +2、红 −2、黄暂停下一回合、蓝固定 ±1、紫接力区。负面效果、护盾、连锁上限、技能冷却、相遇对话、完赛排名均已实现。

## 本次交互与演出升级

- 默认大富翁式斜俯视角，支持正上方、低位、反向四个镜头。可全屏，中键／右键拖动，或开启“拖拽视野”后用左键／触摸平移。
- 绿色桌布任意有效位置可蓄力落锤，落点用射线求交获得；按与骰子中心的方向和距离计算冲击，木边和盘外不接受。
- 传力比例为 `0.12 + 0.88 × exp(−距离 / 2.4)`；偏心落锤沿远离落点方向翻面，近中心锤击更偏弹起散射。
- 每队操作通过队伍颜色、盘面标记、连线和操作卡持续展示。相反的风可以抵消。面板显示已提交力量加当前蓄力的合力预测。
- 骰子临停保持微翘慢摆；全员亮招后短暂定格，合力演出完成才真正落定。
- 格子结算有专属颜色光圈／粒子和短暂停留；主动技能带二次元 CG 横切、速度线和大标题。四套职业原型立绘按技能类别共用，详细提示词见 [美术生成记录](docs/art-direction.md)。
- 场景加入甜品商店、蛋糕城堡、动态摩天轮、喷泉、彩旗和灯带。

## 概率骰子

采用 **离散朝向 + 概率转移 + Three.js 动画**，不使用不稳定的刚体求解器。

骰子保留 24 种合法空间朝向，正反面分别是 1/6、2/5、3/4。吹风翻面按相邻面计算，不能任意跳点。初始 1 朝上、3 在左，向右吹 30% 力度时：

| 结果 | 概率 |
| --- | --- |
| 不变，1 仍朝上 | 1/2 |
| 翻一面，3 朝上 | 1/3 |
| 翻两面，6 朝上 | 1/6 |

力度越高，多翻面的概率越高。振桌允许 0–3 次四分之一圈翻转，风允许 0–2 次。概率预览实时显示；所有动作先提交，不立即改变朝向。各队风向量与落锤冲击合并后只采样一次，提交顺序不会改变概率。骰子动画最终姿态和规则点数一致。强风、重锤、风向扰乱技能也进入概率预览。

当前采用盘内约束的表现动画，不模拟出盘、碰撞摩擦、麦克风和陀螺仪。投掷轨迹不偷偷修改基础点数分布。

## 技术结构

- `src/game.js`：无渲染依赖的规则状态机，40 个技能效果、接力、格子和胜负。
- `src/dice.js`：六面空间关系、随机种子、概率转移。
- `src/scene.js`：Three.js 棋盘、圆角实体骰子、角色、动画与相机。
- `src/main.js`、`src/style.css`：中文菜单、选角、游戏操作、概率预览与房间。
- `server.js`：WebSocket 权威房间服务。服务器生成随机数、控制时间和动作预算；非当前队不能投骰。客人断线后 AI 接管，房主离开后关闭房间。
- `src/data/`：迁移自原 Godot 工程的 40 人和 100 格数据。

联机选角为各自挑选并由房主开赛，当前没有原 ENet 的轮流 30 秒选角计时和重连恢复。本地选角不计时。骰子工坊提供三种可保存的配色；角色装扮库存尚未实现。

原 Godot 项目保留在上级目录，本仓库是独立的网页版。具体迁移取舍见 [迁移说明](docs/migration.md)。

## 验证和构建

```sh
npm test
npm run test:browser
npm run build
npm run preview
```

规则测试涵盖合法朝向、概率频率、无干预均匀性、全部角色定义、完整四队比赛、精确与跨越接力、房间权限。浏览器测试使用 Windows Edge；CI 使用 Chromium，实际点击选角、投骰、吹风、振桌、暂停、移动和双客户端联机，也检查手机布局。

`dist/` 可部署到普通静态托管；联机服务需独立运行。构建资源使用相对路径，适合仓库子目录托管。场景模型由代码生成，技能演出使用仓库内的四套原创 AI 立绘；音效由 Web Audio 合成，无外部 CDN、字体或音乐依赖。
